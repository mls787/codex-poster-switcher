# Codex 海报切换器

一个独立编写的本机小工具：给 Codex 桌面窗口换背景图，保存多张海报并快速切换。**macOS 与 Windows 共用同一套操作界面**。图片只保存在你的电脑上。

这个仓库从空白项目开始编写，**不是任何换肤项目的 fork，也没有复制其他项目的代码或主题图片**。它是非官方工具，与 OpenAI 无隶属关系。它目前只处理**窗口背景**，不替换启动画面、Codex 标志、载入动画或桌宠。

## 三步上手

1. 安装并登录官方 Codex 桌面应用，然后**完全退出 Codex**。
2. 从本仓库的 [Releases 下载页](https://github.com/menglushen787-eng/codex-poster-switcher/releases/latest)下载你系统的安装包，按下面的 Mac 或 Windows 步骤打开海报切换器。
3. 点“添加一张海报”选择自己的 PNG/JPG 图片，再点“启动 Codex 并应用”。切换其他海报时，点图片卡片上的“切换”，**不必重启已连接的 Codex**。

推荐用 16:9 的纯背景图，例如 2560 × 1440。图片不要包含假的聊天框或按钮。单张最多 10 MB；软件不附带任何动漫图片，请自行使用有权使用的图片。

## Mac 安装

1. 下载 `CodexPoster-macOS.zip` 并解压。
2. 把 `CodexPoster.app` 拖进“应用程序”，打开它。它会在浏览器中打开本机设置页。
3. 如果 macOS 提示此应用未签名，先确认文件来自本仓库的 Release；然后在 Finder 中按住 Control 点击应用，选“打开”，按系统提示操作。不要关闭系统安全保护。
4. 导入图片后，确认 Codex 已完全退出，点击“启动 Codex 并应用”。

目前查找 `/Applications/ChatGPT.app` 或 `/Applications/Codex.app` 中的桌面应用；安装在其他位置时会提示未找到。Mac 二进制目前没有 Apple 开发者签名或公证。

## Windows 安装

1. 下载 `CodexPoster-Windows-x64.zip`，解压到一个文件夹。**两个 `.exe` 文件要留在同一个文件夹里**。
2. 双击 `CodexPoster.exe`，浏览器会打开本机设置页。首次打开时，先核对下载来源；当前构建未做代码签名，Windows 可能显示安全提醒。
3. 导入图片，完全退出 Codex，再点“启动 Codex 并应用”。工具会通过开始菜单中注册的 Codex 应用启动它。

Windows 版本面向 **Windows 10/11 x64** 的已注册 Codex 桌面应用。Windows 首次通过调试模式启动时可能使用独立的本机配置目录，需要重新登录。Windows 的真实桌面兼容性仍需更多设备验证；若 15 秒内连接失败，工具会提示原因，**不会循环重启 Codex**。

## 日常切换、恢复与退出

- **换图：** 设置页点“添加一张海报”；上传后自动选中。已连接 Codex 时，立即尝试应用。
- **切换：** 在“我的海报”卡片上点“切换”。设置器保持运行时，会在 Codex 页面刷新后重新应用选中的图。
- **恢复：** 点“恢复官方外观”，随后完全退出 Codex，再从官方入口打开。这样也会关闭这次启动使用的调试端口。
- **退出设置器：** 点页面底部“退出设置器”。这不会替你关闭 Codex；若要结束调试端口，仍需完全退出 Codex。
- **删除图片：** 卡片上的“删除”只删除保存在本机图库中的该图片；删除前会弹出确认。

普通方式重新打开 Codex 时不会自动带海报。要使用海报，先打开本工具，再点“启动 Codex 并应用”。工具不会在后台安装开机任务，也不会自动关闭或重启 Codex。

## 常见问题

**打开工具后没看到浏览器页面？** 再双击一次程序，或检查系统默认浏览器。设置页只运行在 `127.0.0.1`，不会上传图片。

**提示“未发现可换海报的窗口”？** 完全退出 Codex，包括托盘或菜单栏里的后台进程，再点“启动 Codex 并应用”。已经运行的 Codex 可能忽略新的调试参数。

**图片只显示一部分？** 背景会按窗口比例裁切。换用留有边缘空间的 16:9 图片。

**软件更新后背景失效？** Codex 的界面结构可能变化。本工具依靠调试协议附加样式，不能保证所有版本都兼容。可以先点“恢复官方外观”，再到 Issues 说明 Codex 版本和系统版本；不要上传含聊天内容的截图。

## 隐私与安全

工具通过只绑定 `127.0.0.1` 的 Chromium 调试端口，把图片样式临时加入 Codex 页面；**不会修改官方应用文件或代码签名**。这个调试端口没有身份验证，同一台电脑上的其他程序可能连接并读取或操作 Codex 窗口。用完请点击“恢复官方外观”，完全退出 Codex，再从官方入口打开。设置页也只监听本机，修改操作要求本次启动生成的随机令牌。

图片和主题索引保存在本机用户配置目录中的 `CodexPosterSwitcher` 文件夹。程序运行时不联系外部服务；公开发布包通过 GitHub Actions 从仓库源码构建。依赖的 `gorilla/websocket` 按其开源许可证使用。

## 开发与发布

需要 Go 1.27 或更新版本：

```bash
go test ./...
go run .
```

推送到 `main` 会构建 Mac 和 Windows 压缩包；推送 `v*` 标签会在两端构建通过后创建 GitHub Release。Windows 包中的 `codex-activate.exe` 由仓库里的 [`windows/codex-activate.cpp`](windows/codex-activate.cpp) 在 Windows 构建机编译，用于调用系统注册应用的启动接口。
